# Структура и оформление

**О01.** У документа должен быть один заголовок первого уровня; уровни Markdown идут последовательно.

**О02.** В начале инструкции укажите цель, аудиторию и предварительные условия.

**О03.** Каждый пронумерованный шаг содержит одно проверяемое действие; после шагов опишите результат.

**О04.** Нумерованные списки используйте для последовательности, маркированные — для независимых пунктов.

**О05.** Ссылки называйте по назначению: «Откройте каталог курсов», а не «Нажмите здесь».

**О06.** В таблицах указывайте заголовки столбцов; изображения снабжайте альтернативным текстом.

**О07.** Код оформляйте ограждёнными блоками с указанием языка; приводите проверяемые команды и ожидаемый результат.
