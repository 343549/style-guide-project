# Стайлгайд документации LearnPath

LearnPath — **учебный условный веб-сервис** для самостоятельного изучения программирования. Документация предназначена для учащихся и авторов контента. Названия разделов интерфейса приведены как учебные допущения, а не описание действующего приложения.

Используйте разделы руководства при подготовке инструкций, уроков и FAQ. Изменения проходят проверку через Pull Request.
