# Стайлгайд документации LearnPath

LearnPath — **учебный условный веб-сервис** для самостоятельного изучения программирования. Документация предназначена для учащихся и авторов контента. Названия разделов интерфейса приведены как учебные допущения, а не описание действующего приложения.

## Назначение руководства

Используйте разделы руководства при подготовке инструкций, уроков и FAQ.
Правила помогают разным авторам одинаково называть функции, объяснять действия
пользователя и проверять результат. Руководство предназначено также для
рецензентов: [чек-лист](review-checklist.md) превращает правила в проверяемые
критерии.

## Как работать со стайлгайдом

1. Определите задачу читателя и изучите правила разработки
   [инструкции](instruction.md).
2. Подготовьте текст с учётом правил языка и структуры.
3. Проверьте точность примеров и доступность текста.
4. Выполните самопроверку по чек-листу.
5. Откройте Pull Request и передайте документ другому участнику на ревью.

Раздел [«Проверка правил»](testing.md) показывает применение этого процесса к
двум документам LearnPath.

## Область применения

Стайлгайд регулирует пользовательскую и учебную документацию LearnPath. Он не
заменяет требования к программному коду, фирменный стиль или правила защиты
информации организации. Если правило не подходит конкретному документу, автор
объясняет исключение в описании Pull Request.
