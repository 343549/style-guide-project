# Как начать урок

**Для кого:** для нового пользователя LearnPath.

**Цель:** открыть первый урок курса Python.

**Условия:** пользователь вошёл в учебную учётную запись; для примера предполагается наличие курса и урока.

1. Откройте раздел «Каталог курсов».
2. Выберите курс «Основы Python».
3. Откройте урок «Переменные».
4. Нажмите «Начать урок».

**Результат:** откроется учебный материал урока.

**Если урок недоступен:** проверьте, завершены ли обязательные предыдущие уроки. Если проблема сохраняется, обратитесь к администратору курса.

> Названия интерфейса являются допущениями учебного примера.
