# Шаблоны документов

**Ш01.** Инструкция: назначение, условия, шаги, ожидаемый результат, решение типичных проблем.

**Ш02.** Описание урока: цель, необходимые знания, материал, пример, самостоятельная проверка.

**Ш03.** FAQ: вопрос формулируйте языком пользователя, ответ начинайте с прямого решения.

**Ш04.** Описание ошибки: наблюдаемый симптом, возможные проверяемые причины, действие пользователя, способ обратиться за помощью.
