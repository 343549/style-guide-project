# Язык и терминология

**Л01.** Пишите для начинающих пользователей: обращайтесь на «вы», избегайте оценок сложности и канцеляризмов.

**Л02.** Используйте повелительное наклонение для действий: «Откройте курс», а не «Осуществляется открытие курса».

**Л03.** Одно понятие — одно название: «урок», «курс», «задание», «прогресс»; не заменяйте их синонимами.

**Л04.** При первом употреблении объясняйте сокращения; используйте букву «ё» и русские кавычки «ёлочки».

**Л05.** Названия элементов интерфейса воспроизводите дословно и заключайте в кавычки. Не выдумывайте реальные функции.

**Л06.** Даты пишите «9 октября 2026 года», время — «14:30», длительность — «15 минут»; указывайте часовой пояс при необходимости.
