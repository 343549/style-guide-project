# Чек-лист проверки

- [ ] Целевая аудитория и цель ясны.
- [ ] Названия интерфейса одинаковы.
- [ ] Шаги описывают одно действие каждый.
- [ ] Указан ожидаемый результат.
- [ ] Есть действия при ошибке.
- [ ] Ссылки и примеры проверены.
- [ ] Изображения имеют альтернативный текст.
- [ ] Заголовки идут последовательно, без пропуска уровней.
- [ ] Состояния и ошибки объясняются не только цветом или значком.
- [ ] Сокращения и единицы измерения расшифрованы.
- [ ] Учебные допущения отделены от реализованных функций.
- [ ] В примерах отсутствуют пароли, токены и персональные данные.
